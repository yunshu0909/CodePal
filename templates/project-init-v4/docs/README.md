# docs/ — 沉淀知识库

跨版本、长生命周期的内容放这里。`specs/` 是单元级留档（做完不动），`docs/` 持续生长。

## 目录

- `plan/` — 滚动计划：Issue 池里拆出的大计划落在这里，交付一批回来续拆一批
- `research/` — 调研、决策分析、复盘报告（给人看的用本地 HTML）
- `archive/` — 被替代的旧计划和旧结论，只在追溯时看
- `issue-check.py` — Issue 池工具：新建 / 改状态 / 关闭 / 生成总览 / 检查；规则见 `issues/README.md`
- `protocol-check.py` — 协议检查：两份协议是否一致、写到的路径是否存在、体积是否超预算

## 沉淀规则

- 设计规范、代码规范这类东西不预先写，某种做法在两三个任务里反复稳定了，再沉淀到这里，并在协议「8. 知识地图」登记。
- 同一件事只在一个地方写，其余地方链接过去。
- 被替代的内容挪进 `archive/`，不直接删除。
